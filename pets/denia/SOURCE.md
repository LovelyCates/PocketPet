# Denia / 达妮娅

User-provided character package included with the project owner's authorization.

The character design is fan content inspired by Wuthering Waves. Character names, designs and associated rights remain with their respective owners. This package is not official or endorsed by the game's publisher.

The original WebP pixels are unchanged. `pet.json` adds a collection label and enables an optional runtime green-fringe filter; it does not replace the source artwork.
